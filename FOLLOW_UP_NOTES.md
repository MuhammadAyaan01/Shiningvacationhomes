# Guest-journey refinements — 13 November 2026

User approved the preceding review recommendations and requested automatic motion without a visible switch or bar. Implemented the changes supported by current verified content:

- Full motion starts on every page. No motion preference UI or persisted setting is read. The old preference module and its generated output were removed.
- Removed the top preview bar; the footer retains an honest note about the unconnected booking and email-draft enquiry behaviour.
- Changed property/hero photo controls to “Explore collection photos.” The dialog explicitly explains that it browses reference photographs across property types, rather than a gallery for one individual home.
- The Contact page places its enquiry form before secondary contact information in document order and on mobile. Desktop retains the left contact information / right form presentation.

Motion is deliberately automatic regardless of the device reduced-motion preference, following the user's explicit instruction. Native scrolling, keyboard controls, dialog focus return and visible static content remain intact.
